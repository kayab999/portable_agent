# ADR 006 — RAG baseline is lexical FTS5/BM25

Status: accepted

## Decision
Use SQLite FTS5 with BM25 as the retrieval baseline. No embedding model is
required at runtime.

## Rationale
Zero runtime dependencies, deterministic offline behavior, low latency and no
additional model download. Lexical retrieval is sufficient for a curated local
corpus.

## Consequences
- Semantic paraphrase recall is weaker than embeddings.
- Embeddings can be added later as an optional, separately gated backend.
